Public records, made usable

New Mexico's public records, turned into accountability.

The New Mexico Impact Lab collects government data from across the state (the Legislature, campaign money, lobbying, courts, and public spending) then cleans it, structures it, and publishes it so anyone can search it.

What we work on

We follow money and power across all three branches of New Mexico government. Each project starts as records the state already publishes one page at a time, and ends as a database you can search in one query.

How we work

1. Collect

We gather records that are legally public but scattered across agency websites and one-page-at-a-time portals, and we keep the original file for every one.

2. Structure

We reconcile names and dates across systems that do not share identifiers, and keep the original value next to the cleaned one.

3. Publish

We put the results online, free to search, so the public doesn't have to file a records request to see it. See our methodology and what each dataset is missing.
